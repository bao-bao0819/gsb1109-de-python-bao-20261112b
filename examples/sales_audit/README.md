# 销售表遮盖格反推核查工具

在通过 pyexcel-io 把供应商销售表入库前，先核查被遮住的格子能否仅凭**仍公开的
行小计、列小计和业务上下限**反推出**唯一整数**。空白格一律按"未知"处理，绝不
当作零。

## 用法

```bash
python -m sales_audit examples/sales_audit/unique/spec.json
```

退出码：`0` 唯一可推；`3` 多解（留在待核区）；`2` 供应商小计/上下限矛盾；
`1` 规格或环境错误（核查未能进行）。

也可作为库使用：`run_spec(path)` / `load_workbook` + `parse_sheet` +
`audit_sheet`，读取链路与入库一致，均走 `pyexcel_io.get_data`。

## 核查规格 spec.json

- `table`：销售表路径（相对 spec.json 解析），支持 pyexcel-io 能读的格式。
- `sheet_name`：多 sheet 工作簿时指定，缺省取第一个。
- `header_rows`：表头行下标（从 0 起），表头不参与求解，仅用于展示与定位。
- `label_col`：行标签列；`row_total_col`：行小计列。
- `col_total_rows`：列小计行下标列表；`grand_total_row`：总计行（须同时在
  `col_total_rows` 内），缺省表示不校验总计。
- `masks`：遮盖记号列表（如 `["?"]`、`["***"]`）；未列出的空白单元格也视为
  未知遮盖格。显式写出来的 `0` 是公开数据，不会被当成遮盖。
- `bounds`：业务上下限，端点用 `null` 表示无穷。
  - `default`：全局默认区间，缺省 `[0, null]`。
  - `rows` / `cols`：按行/列覆盖，键为 0 起下标。
  - `cells`：按格覆盖，键为 `"行,列"`（0 起下标），多层取交集。

## 三种结论

- `UNIQUE`：约束传播（必要时分支限界全域枚举）后只有一组整数解，报告逐格
  列出反推依据（由哪条行/列小计收紧为单点）。
- `MULTIPLE`：存在多组解，报告给出**两张都满足整张表**的完整填法，并列出
  取值不同的格子作为不唯一的证据。
- `CONFLICT`：行/列小计彼此打架，或小计落在上下限可行区间之外，不存在任何
  整数解。报告会单独指出矛盾数字，绝不把"无解"误报成遮盖反推成功。

若存在只受方程约束、定义域无界（缺业务下限或上限）的自由格，工具会直接报
`NeedBoundsError` 要求补边界，而不是在无界空间里猜测。

## 样例目录

- `unique/`：4 个遮盖格可唯一反推，含逐格依据。
- `blank_unknown/`：同一张表用空白表示遮盖，验证空白不当零。
- `multiple/`：2x2 全遮盖，给出两份完整可行填法。
- `conflict/`：列小计与行小计合计差 1，明确报矛盾。
